# ADMITRA – Screenshots

Real screenshots of every screen, taken from the running application with the demonstration data (`npm run seed:demo`) on 20 November 2026 (updated after Phase 5: Mitra, branding and RIT's own colors).

- `desktop/` – laptop screen of 1440 × 900 px, exactly what is visible on the screen
- `mobile/` – iPhone 13 screen (390 px wide), exactly what is visible on the screen
- `dark/` – a selection in the dark theme (`mobile-` files are phone screens)

The pages opened from e-mail links (verify e-mail, reset password, accept invitation) use the same layout as Log in and need a fresh link, so they are not included.

Accounts used: public pages without login; applicant Ayesha Noor (Hamza Ali for the payment page); Institution Admin of Riverside Institute of Technology (Crescent Valley University for marks verification and support); Super Admin.
